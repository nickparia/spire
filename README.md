# Spire

One-thumb stacking game. Tap to drop the slab. Match the groove. Five perfects forge it wider. Each sky keeps a different time, and a bomb means wait.

## Download

On your phone or computer, open this link. It saves a zip of the code:

https://github.com/nickparia/spire/archive/refs/heads/main.zip

Or on this page: green **Code** button → **Download ZIP**.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:8080. Needs Node 22.
